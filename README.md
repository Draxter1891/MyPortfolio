# Rishabh Tripathi — Portfolio

A personal portfolio website built with vanilla web technologies, featuring smooth animations, custom cursor effects, and a responsive layout.

**Live:** [rishabhtripathiportfolio.vercel.app](https://rishabhtripathiportfolio.vercel.app)

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | SCSS → Compiled CSS |
| Logic | Vanilla JavaScript (ES6+) |
| Deployment | Vercel |

---

## Features

- Custom animated cursor with blur glow effect
- Scroll-based animations and interactions
- Draggable horizontal project cards
- Responsive design for mobile and desktop
- Social links sidebar
- Contact form section

---

## File Structure

```
MyPortfolio/
├── index.html          # Main HTML file
├── script.js           # Cursor, scroll, and interaction logic
├── stylesheet.scss     # Source styles (edit this)
├── stylesheet.css      # Compiled CSS (auto-generated)
├── stylesheet.css.map  # Source map for debugging
└── README.md
```

> Edit `stylesheet.scss`, not `stylesheet.css` — the CSS file is auto-generated and will be overwritten.
